## SUIRO架空化粧水 LP：構造置換マニフェスト

### 1. 前提・実測値

参照したSIROK Basic LPの実測値：

- 基準キャンバス：**750px幅**
- 総高：**66,087px**
- 画像：**116点**
- 動画：**9本**
- フォーム要素：**8フォーム**
- PC/SPともコンテンツ順と動画位置はほぼ共通
- SP実測は `clientWidth: 390px` に対し `scrollWidth: 600px` で、**横方向にはみ出す固定幅的な実装**
- 以下の区間はコンタクトシートからの視覚推定。動画位置はDOM実測値

SUIROで確定している表示可能情報は、次の5点に限定する。

- **SUIRO 化粧水**
- **150mL**
- **3,520円（税込）**
- **無香料**
- **朝夜、少量を2回に分けて使用**

口コミ、受賞、割引、定期便条件、効能、成分、臨床データ、比較優位は未確認のため掲載しない。

## 2. ページ全体の構造原則

SIROKから転用してよいのは、次のような抽象的な構造文法に限る。

- 750px基準の縦長・単列構成
- 「情緒的導入 → 商品理解 → 使用方法 → 商品情報 → 購入導線」の順序
- 白／淡色の長い説明区間に、濃色の章扉と短いオファー帯を差し込むリズム
- 同一の商品情報を長いページの節目で再提示する方式
- 中盤以降に動画を集中配置する方式
- 最後に商品情報、注意事項、購入フォーム、フッターを置く方式

ただし、**画像、文章、ロゴ、賞マーク、図解、人物、動画、商品パッケージ、配色の完全模倣は行わない**。

### 各セクションの実装内容

#### 01. ファーストビュー
必須表示：

- SUIROのオリジナルロゴまたは文字ロゴ
- オリジナルの商品写真
- 「化粧水」「150mL」
- 「3,520円（税込）」
- 無香料
- 朝夜使用

見出しは効能断定ではなく、使用行為やブランド姿勢を表現する。

使用可能例：

- 「朝と夜、肌に向き合うための化粧水」
- 「少量ずつ、2回に分けてなじませる」
- 「香りを加えない、毎日の化粧水」

避ける表現：

- 「うるおいが続く」「毛穴改善」「透明感」「敏感肌向け」など、未確認の効能・適性表現

#### 02. 使用イメージ
人物または手元のオリジナル写真を使い、朝夜の生活シーンを提示する。肌変化のBefore/Afterは置かない。

#### 03. 商品概要／オファー1
商品カードとして以下だけを掲載する。

> SUIRO 化粧水
> 150mL
> 3,520円（税込）
> 無香料
> 朝・夜、少量を2回に分けて使用

割引率、通常価格との二重価格、セット特典、送料無料、定期縛り、残数表示は入れない。

#### 04. コンセプト
受賞歴や第三者評価の代わりに、確認可能なブランドステートメントを置く。ブランドストーリーが未確定なら、短い使用思想に留める。

#### 05. 使用シーン
「朝」「夜」の2場面を写真で見せる。ユーザーコメント風の吹き出しやSNS投稿は使用しない。

#### 06. オファー2
03と同じ商品情報を短く再掲する。表現と価格を変えず、虚偽のキャンペーン感を出さない。

#### 07. 一般的な使用上の迷い
「化粧水を一度に多く使うか、少量ずつ使うか」など、SUIROの確認済み使用方法へ自然につなぐ。肌悩みの治療・改善を示唆しない。

#### 08. 使用方法の予告／オファー3
「少量を2回」という確認済み仕様を中心にする。1本で何日分かは未確認のため掲載しない。

#### 09. テクスチャー導入
液体、ボトル、手元の接写を配置。ただし「さらさら」「とろみ」「浸透」なども、実物確認前は断定せず、映像・写真による視覚提示に留める。

#### 10〜13. 動画中心のHOW TO
9本の動画は後述の位置で配置。すべてSUIRO用に撮影・生成した権利確認済み素材とする。

#### 14. 商品再提示
実演後に、商品名・容量・価格・使い方を再度まとめる。

#### 15. 梱包・配送情報
配送方法、送料、発送日数、返品条件が確認できていない場合は、SIROKの配送訴求を置換しない。代わりに動画9を商品外観または開封イメージとして使う。実物発送仕様と異なる梱包を確定情報のように見せない。

#### 16. 商品仕様・注意事項
確定情報のみを表形式で掲載する。

| 項目 | 掲載値 |
|---|---|
| 商品名 | SUIRO 化粧水 |
| 内容量 | 150mL |
| 価格 | 3,520円（税込） |
| 香り | 無香料 |
| 使用タイミング | 朝・夜 |
| 使用方法 | 少量を2回に分けて使用 |

全成分、製造販売元、原産国、使用上の注意などが未確認なら、空欄を埋めず公開前ブロッカーとする。

#### 17. 最終商品確認
価格と容量を大きく再掲し、購入前に確認すべき情報を並べる。比較表を置く場合も、販売チャネル間の価格比較や「公式が最安」などは実証なしに掲載しない。

#### 18. 申込フォーム／フッター
フォームと法定・運営情報をまとめる。詳細は後述。

## 4. 色リズム

参照LPは、概ね次のリズムになっている。

1. 白・生成りの長い説明面
2. ブラウン／ゴールドの濃色章扉
3. 黄〜オレンジ系の商品オファー面
4. 再び白い読み物面
5. HOW TOで写真中心の淡色面
6. 終盤に濃色の注意帯と白い商品情報面

SUIROでは同じ「明暗リズム」だけを採用し、SIROK／N organic固有の琥珀色・金色の組み合わせは避ける。

### SUIRO向け推奨リズム

- ベース：水白、淡い青灰、ニュートラルなオフホワイト
- 章扉：深い青緑またはチャコール
- 商品カード：白＋淡い水色
- CTA：高コントラストの青緑または濃紺
- 注意・未確定表示：灰色
- 価格：本文色と同系統。赤による過度な値引き演出はしない

配色の反復単位：

> 白 2〜3セクション → 淡色1セクション → 濃色の短い章扉 → 白 → 商品カード

SIROKの金茶背景、赤い価格矢印、金色の受賞リースをそのまま再現しない。

参照LPでは、短い商品セット訴求と詳細比較表がページ各所に反復している。SUIROでは、割引やセットを捏造せず、**同一の商品情報カードを5〜6回**置く。

2. **商品コンセプト後**：オファー1
3. **使用方法導入前**：オファー2
4. **HOW TO直前**：オファー3
5. **HOW TO直後**：オファー4
6. **フォーム直前**：最終オファー

### 各回で変えない情報

- 150mL
- 3,520円（税込）
- 無香料
- 朝夜
- 少量を2回

### CTA条件

購入先URLが実在・確認済みの場合のみ「購入する」を使用する。未確定なら：

- 「商品情報を確認する」
- 「お申し込み準備中」
- 「デモフォーム」と明示した非送信UI

を使用し、架空の決済完了や在庫連動を作らない。

## 8. SP挙動

参照LPのSP実測は、390px画面に対して600px幅のコンテンツが残るため、横スクロールまたは左右欠けが発生する。これは再現対象ではなく、修正対象とする。

### SUIROのSP仕様

- PC：コンテンツ幅最大750px、中央寄せ
- SP：`width: 100%`、360／390pxに適応
- `scrollWidth === clientWidth` を必須条件とする
- 単なるPC縮小ではなく、SP専用の画像クロップと改行を使用
- 2カラム情報は縦積み
- 比較表を使う場合はカード化し、極小文字を避ける
- CTAのタップ領域は44px以上
- 固定CTAはファーストビュー直後からではなく、商品理解ブロック通過後に表示
- 固定CTA非表示時は `inert` と `aria-hidden` を設定
- 下部CTAは端末のsafe areaを考慮
- 動画はSP用縦長または正方形素材へ切り替える
- 360px／390px／768px／750px以上で日本語の孤立改行と横あふれを確認
- 長いページでも9動画を一括ロードしない

PC/SPでセクション順は変更せず、ファーストビュー、商品情報、使用方法、フォームの優先度だけを保つ。

## 10. 実装上の合法的な置換方針

### 維持してよいもの

- 長い単列LPという形式
- セクションの疎密
- 明色と濃色を交互に置くリズム
- 商品情報カードの反復
- 中盤以降へHOW TO動画を集中させる考え方
- 終盤で商品情報とフォームへ収束させる流れ

### SUIRO独自に作るもの

- ロゴ、容器、ラベル、外箱
- 写真、人物、手元、背景
- 動画9本
- コピー
- アイコン、図解
- 配色・タイポグラフィ
- 商品カード
- CTA形状
- フォームUI
- ブランドストーリー

### 非捏造ゲート

公開前に、画面内の主張を次の3分類で監査する。

- **確認済み**：そのまま掲載可能
- **未確認**：非表示または「情報準備中」
- **禁止**：口コミ、賞、割引、効能、成分など、埋め草として生成しない

総高を参照LPへ近づけるために、未確認の成分説明、レビュー、Q&A、ブランド沿革を増やしてはならない。コンテンツが不足する場合は、**ページを短くすることが正解**。

## まとめ

- SIROK Basic LPは、約66,000pxの単列構成で、**商品オファーを5〜6回再提示し、ページ後半に9動画を集中、末尾を注文情報とフォームへ収束**させる設計。
- SUIROではこの販売リズムのみを転用し、表示情報を「150mL／3,520円税込／無香料／朝夜／少量を2回」に限定する。
- 受賞、口コミ、割引、効能、成分、比較表、配送・定期条件は、確認できるまで掲載しない。
- SIROK固有のロゴ、商品写真、茶色いパッケージ、人物写真、動画、金茶配色、賞マーク、コピー、価格表は再現しない。
- SPの600px固定幅による横あふれは踏襲せず、360／390pxで完全レスポンシブ化する。
- **ファイルの作成・変更は行っていない。**
- 問題点：末尾フォームの実際の表示位置はDOM上で固定／非表示状態が混在しており、8フォームという数は8つの独立した可視フォームではなく、注文フローの複数状態を含む可能性が高い。
