# SUIRO化粧水向けページマニフェスト

## 1. 観測値と置換方針

- 参照LP実測：**幅750px／高さ48,841px**
- 画像：102点
- 動画：13本
- DOM上の`form`：8個
- SP実測：`clientWidth: 390px`に対して`scrollWidth: 600px`
  - 参照LPには横方向のはみ出しがあるため、これは**再現しない**
- 継承してよいもの：
  - 長尺LPとしての情報密度
  - セクション順と緩急
  - 淡色→黄色→茶色→淡色という色面のリズム
  - 動画を少数ずつクラスター配置する構造
  - 商品情報・CTAの反復
  - 最終オファーから末尾フォームへ接続する流れ
- 継承してはいけないもの：
  - 固有コピー、固有画像、動画、ロゴ、商品外観、人物、受賞表現、モール表示、レビュー、フォームUI、装飾図形など

以下の高さは48,841pxを基準にした**構造上の目安**であり、総丈を合わせるための空白や`min-height`は使用しない。

## 3. 色リズム

色面の順序だけを参照し、元LPの色値・グラデーション・テクスチャは複製しない。

### SUIRO用の独自パレット例

- 淡色ベース：ミスト系アイボリー／青緑
  `#F5F7F3`、`#EAF2EF`
- 黄色アクセント：ややくすんだバターイエロー
  `#F2D86B`
- 茶色アンカー：深いココアブラウン
  `#55392C`
- 本文：
  `#2D2926`
- 茶色面上の文字：
  `#FFF9ED`

### 長尺全体のリズム

```text
淡色
→ 淡色
→ 小さな黄色
→ 淡色
→ 大きな黄色
→ 茶色
→ 淡色
→ 黄色＋茶色
→ 淡色
→ 茶色
→ 淡色
→ 最終茶色
→ 白いフォーム／フッター
```

- 黄色は「価格訴求」ではなく、**仕様・使用手順の理解促進**に使う。
- 茶色は全体の区切りや動画帯の背景として使用。
- 淡色面を最も長くし、黄・茶を連続させすぎない。
- 小さい文字に薄い黄色や茶色を使わず、WCAG AA相当のコントラストを確保する。

### 動画禁止事項

- 参照LPのMP4 URL・フレーム・構図・モデル・小物を流用しない
- 塗布前後比較を作らない
- 毛穴、乾燥、透明感などの改善を映像で暗示しない
- 「浸透」「肌が変わる」等の未確認テロップを入れない
- 口コミ投稿や一般消費者の自撮りに見せかけない
- 季節限定パッケージや限定ギフトを描かない
- テキストを動画へ焼き込まず、HTML側に置く

### 再生実装

- FV以外は`preload="metadata"`
- `IntersectionObserver`で画面付近のみ再生し、画面外で停止
- `muted loop playsinline`
- 全動画に静止画ポスターを設定
- `prefers-reduced-motion`とデータセーバーでは静止画へ切り替え
- SP用には別クロップを用意し、人物や手元がコピーと衝突しないようにする
- MP4は`faststart`処理を行う

## 5. オファー反復

同じ商品カードを**5回**、閲覧者の疑問が一区切りつく地点に配置する。

1. 初期商品理解後：3,100–4,400px
2. 仕様説明後：10,000–12,000px
3. 前半実演後：20,000–24,000px
4. How to Use後：38,000–40,000px
5. 末尾フォーム直前：43,000px以降

### 全オファーで使用可能な情報

```yaml
product_name: SUIRO 化粧水
category: 化粧水
capacity: 150mL
price_tax_included: 3,520円
fragrance: 無香料
timing:
  - 朝
  - 夜
usage:
  - 少量を手に取る
  - 2回に分けてなじませる
```

### オファーに追加してはいけない情報

- 初回価格、割引率、定期価格
- 送料無料
- 返金保証
- 残り在庫、締切、期間限定
- 季節限定
- 特典、ポーチ、ミラー、サンプル
- 何日分・何か月分
- 売上順位・人気順位
- 「おすすめ」「一番人気」などの根拠のない優良性表示

購入先が未確定なら、CTAは送信させず、プレビュー上で「購入先設定前」または「デモ」と明示する。架空のチェックアウトURLを作らない。

## 6. 末尾フォーム

参照DOMの「8 forms」は、8回フォームを表示しているという意味ではなく、固定式チェックアウトや段階別画面が複数DOMに存在する可能性が高い。SUIROでは**8フォームをコピーせず、末尾に1つのフォームコンポーネント**を置く。

### 推奨構造

```text
最終商品情報
→ 150mL／3,520円（税込）
→ 無香料／朝夜／少量を2回
→ CTA
→ フォーム
→ 同意・注意事項
→ FAQ
→ 法務フッター
```

### 本番購入フォームに必要な未確定事項

- 販売主体
- 販売ページ／決済エンドポイント
- 配送地域・送料
- 支払方法
- 発送時期
- 返品・キャンセル条件
- 特定商取引法表示
- 個人情報の利用目的
- プライバシーポリシー
- 完了・失敗・再試行・二重送信防止の挙動

これらが確定するまでは、購入フォームを本番送信可能にしない。

### デモ表示にする場合

- `action: null`
- `productionReady: false`
- 「このフォームはデザイン確認用で、送信されません」と明示
- 性別、生年月日、住所、電話番号、支払情報は収集しない
- 連絡希望フォームなら、メールアドレスと同意チェック程度に限定
- カードブランドロゴ、後払いロゴ、SSL安全表示を架空で掲載しない

## 7. SP挙動

- PC：本文最大幅750pxで中央配置
- SP：`width: 100%`、固定600pxキャンバスを使わない
- 360px、390px、768pxで検証
- 横スクロールは常に0
- 画像・動画は`max-width: 100%`
- PC版を縮小するのではなく、SPでは情報順を再構成する
- 2カラムは1カラム化
- 表は縦積みの定義リストへ変換
- 動画の縦横比は用途別に固定し、元の841px等をSPへそのまま適用しない
- 見出しは意味単位で改行し、1〜2文字だけの孤立行を避ける
- CTAのタップ高は44px以上
- モバイル固定CTAを使う場合：
  - FV直後から常時出さない
  - 最初のオファー帯を通過してから表示
  - 非表示時は`aria-hidden`に加えて`inert`
  - フォーム付近では解除または非表示
- 参照LPの全画面固定注文パネルはコピーしない
- 固定CTAを含まない状態でも、本文内オファーだけで購入導線が成立する設計にする

## 9. 実装上の最終原則

参照LPから移植するのは、**長尺の販売リズム、色面の交替、動画クラスター、オファー反復、末尾フォームという抽象構造だけ**とする。

見た目の同一性を避けるため、SUIRO側では以下を独自化する。

- ボトルとパッケージの形状
- 写真・動画の人物、場所、照明、構図
- タイポグラフィ
- 色値
- 見出し構造
- CTA形状
- セクション境界の図形
- アイコン
- コピー
- フォームUI

**ファイルの作成・編集は行っていません。**
分析には指定されたコンタクトシートと`selected-metrics.json`の実測値を使用しました。
